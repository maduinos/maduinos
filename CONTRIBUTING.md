# Contributing

This profile repository documents how the public Maduinos GitHub account is organized.

## Scope

Good contributions include:

- Improvements to the profile README.
- Better repository operations notes.
- Safer repository helper scripts.

Out of scope:

- Customer-specific project details.
- Private business documents.
- Changes that make hobby/lab repositories look like the main FPGA business portfolio.
