운영 흐름

저장소 작업은 로컬 점검, 요청된 커밋·푸시, 공개 문서 관리로 나누어 처리합니다. 이 프로필 저장소는 전체 작업 폴더를 어떻게 다룰지 기록하는 기준 문서 역할을 합니다.

1. 로컬 점검

작업 폴더에서 변경된 저장소의 소스와 문서를 확인하고, 사용 가능한 도구로 문법 오류를 점검합니다.

2. 저장소별 커밋

커밋 요청이 있으면 변경된 하위 저장소에서 변경 내용과 작성자 설정을 확인하고 커밋합니다.

3. 요청된 푸시

사용자가 푸시를 요청하면 대상 저장소의 원격과 브랜치를 확인한 뒤 진행합니다.

4. 범위 구분

대표 프로젝트, 개인 실험, 웹사이트를 구분하고 공개 배포와 소스 공개 범위를 정확히 안내합니다.
